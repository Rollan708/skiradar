# 🧪 [TEST / SANDBOX] SkiRadar — Тестовый прототип агрегатора горнолыжного снаряжения

> **Статус проекта:** `ARCHIVED / TEST SANDBOX` — учебно-тестовый стенд для проверки архитектуры парсинга, нормализации карточек (`Entity Resolution`) и расчёта совместимости горнолыжного сетапа. Фоновые сервисы остановлены, ресурсы освобождены.

Полноценный Full-Stack агрегатор горнолыжного снаряжения (**Bun + SQLite + React 19 + TypeScript + Tailwind CSS v4**), объединяющий витрины магазинов России (*Кант, Триал-Спорт, Траектория, Спорт-Марафон, Альпиндустрия*), Казахстана (*Limpopo Outdoor, Skadi Ski Shop, Extremal.kz*) и зарубежных дискаунтеров (*Sport-Conrad, Evo, Snowleader*).

## Ключевые возможности
1. **Единые карточки моделей (`Golden Record`)**:
   - Автоматическая склейка карточек одного товара из разных магазинов и сезонов (`2024/2025` и `2025/2026`).
   - Отображение реального наличия конкретных ростовок лыж (`170`, `172`, `180`, `186` см) и размеров ботинок (`Mondopoint 26.5, 27.5`) в каждом магазине.
   - Мультивалютный пересчёт на лету (`₽ RUB`, `₸ KZT`, `€ EUR`, `$ USD`) + история динамики цен за 6 месяцев.
2. **Интерактивный «Сборщик сетапа» (`Ski Setup Builder`) + Калькулятор DIN (ISO 11088)**:
   - Расчёт рекомендуемой ростовки, жесткости ботинок и усилия срабатывания креплений **DIN** по росту, весу, размеру колодки и стилю катания.
   - Инженерная проверка совместимости: ширина ски-стопа креплений к талии лыжи (`+0…15 мм`), стандарт подошвы ботинка (`GripWalk ISO 23223`, `Alpine ISO 5355`, `Touring ISO 9523 / Pin`, `Multi-Norm MNC/MN`).
3. **Soothski-Style Компаратор геометрии**:
   - Визуальное наложение контуров бокового выреза (носок / талия / пятка) до 3 пар лыж одновременно.
4. **Лаборатория парсинга и нормализации (`Scraper & Entity Resolution Studio`)**:
   - Живой парсер URL (`Schema.org JSON-LD`, `OpenGraph`, DOM-селекторы) и нормализатор сырых названий (включая кириллическую транслитерацию и защиту от смешивания `Flat` и комплектов `С креплениями`).
   - Управление магазинами-донорами, очередь спорных склеек (`Entity Resolution Queue`) и логи обхода.
